The Epistemic Stack

FLF Epistemic Case Study Competition — interactive pipeline explorer · V3.8

Sources
papers · reports · debates · datasets
▼
No format constraints. Scientific papers (with DOI), arXiv preprints, government reports, blog posts, debate transcripts, and institutional documents all enter the same pipeline. Any source with a verifiable identifier is eligible.
input: any textual source with DOI, arXiv ID, or URL
Ingestion layer
ACE extraction · Source Fidelity Check · Semantic Anchor Hierarchy
▼
ACE extraction: isolates one atomic claim element per node — a single falsifiable assertion, stripped of surrounding rhetoric and hedges.
Source Fidelity Check source_fidelity.py: automated 9-state taxonomy. First verifies identifier existence against Crossref and arXiv registries — a DOI or arXiv ID confirmed absent (HTTP 404) is flagged SOURCE_FABRICATED; a check that fails for network reasons is reported as UNCERTAIN instead, since an inconclusive check is not evidence of fabrication. Then fetches source text and uses an LLM to compare verbatim_claim against it, producing verdicts from RETRIEVED_ALIGNED to RETRIEVED_MISALIGNED. Never modifies systemic_confidence_score automatically — flags for curator review only.
Run against real data on July 13, 2026: executing this against all 26 nodes with a live API key surfaced two implementation bugs, both fixed (a network-failure/confirmed-absence conflation that misreported real sources as fabricated, and a crash on empty API responses consistent with a safety refusal on genomic terminology). After the fix, of 26 nodes checked: no false fabrication flags; 2 blocked by API-level refusal; 10 returned SOURCE_UNREACHABLE (fetch failed outright); 12 returned UNCERTAIN (page retrieved but not its actual content — a related but distinct symptom of the same fetcher limitation); 1 node fully verified; 1 flagged for a discrepancy later found to be two-thirds a false positive on independent primary-source check. Full account in Part 5.1 of the written submission.
Semantic Anchor Hierarchy: tags each claim with epistemic modality (empirical inductive, mechanism causal, observational correlational). Currently a manual annotation in the schema; not yet automated in the pipeline.
scales with better LLM extraction capability
Structure layer
Typed DAG: SUPPORT · CONTRADICT · DEPEND · CONTEXT_MUTATION
▼
SUPPORT: claim A provides positive evidence for claim B.
CONTRADICT: claims are in direct factual opposition — same question, conflicting answers.
DEPEND: claim B's validity presupposes claim A. Used to trace shared methodological ancestry across sources that appear independent but ultimately rest on the same foundational claim or dataset.
CONTEXT_MUTATION: claims agree on the underlying facts but construct structurally different causal narratives around them. Prevents false CONTRADICT edges for methodological frame mismatches. See the second tab for a worked example.
Cycle detection: the DAG invariant is enforced at every compounding step. A proposed edge that would create a cycle is caught before activation and rolled back with a log entry.
deterministic — no model dependency at runtime
Assessment layer
Crux Score · Z-score · CDI · ELM · Ag-Vacuum
▼
Crux Score: Cs = Σ(Dout × Wdep) + Σ(Econ). Contradiction edges are weighted by the contradicting source's peer scrutiny and confidence — not just counted. Wdep multipliers: peer-reviewed & endorsed = 1.0, peer-reviewed = 0.9, gov oversight = 0.8, institutional report = 0.7, unreviewed preprint = 0.5, speculative = 0.3.
Z-score pruning: Z = (Cs − μ) / σ across all nodes in the same case graph. Nodes with Z > 2.0 are flagged as critical. Adaptive threshold — scales to graph density instead of using an arbitrary fixed cutoff. In the current 26-node dataset, no node crosses this threshold in normal operation (COVID's highest is Z = +1.77), which is reported transparently rather than tuned to force a positive result.
CDI — Contradiction Diversity Index: normalized entropy of the sources producing CONTRADICT edges toward a node. CDI ≈ 0 signals that all contradiction pressure originates from a single analyst (possible flooding); CDI ≈ 1 signals genuine independent criticism from multiple distinct sources.
ELM / Prestige-to-Data Ratio: detects authority shielding — when a claim's evidential chain terminates in institutional prestige rather than primary empirical data. Currently a manually applied heuristic; not yet an automated classifier.
Ag-Vacuum: identifies the single highest-leverage missing input — the gap whose resolution would most shift the graph's Crux Score distribution. Output is a specific, falsifiable pointer: "absence of pre-2019 WIV screening logs" rather than "more research is needed."
scales with better reasoning models for LLM-assisted steps
Compounding layer
Multi-analyst merge · deduplication · cascading recalculation
▼
Proposed node: a second analyst submits a new ACE. The system checks Jaccard lexical similarity (default threshold 0.35) against all existing nodes before insertion — near-paraphrases are flagged as possible duplicates rather than silently added.
Edge acceptance: pending edges activate only after cycle detection passes. The Crux Score and CDI of every downstream node are then recalculated and the changes logged with the proposing analyst's ID and a timestamp.
Two-graph demo compounding_two_graphs.py: merges Graph A (genomics + Rootclaim debate) with Graph B (Pekar 2022 molecular clock + WHO-China report). The merge produces a real deduplication flag (0.64 Jaccard on a Worobey near-paraphrase), a CONTEXT_MUTATION conflict on the WIV database interpretation, and cascading score recalculations. Both graphs were constructed by the same team from different starting sources — not by independent teams, which is noted as a limitation.
scales with more contributors and more compute per verification step
Knowledge artifact
structured · interrogable · extendable by any team
▼
Single source of truth: nodes_master.json — document, code, and CLI all derive from this file. They cannot drift from each other. Verified with python3 -m epistemic_stack.cli verify-sync.
One-command summary: python3 -m epistemic_stack.cli summary produces a ranked list of contested nodes with Crux Scores, Z-scores, and CDI in under one second from a clean clone with no setup beyond Python 3.10.
Extendable: a second team proposes nodes via the compounding CLI without modifying the existing graph. The timestamped changelog records who proposed what and what the downstream effects were.
26 source-verified nodes · 11 passing tests · zero external dependencies
